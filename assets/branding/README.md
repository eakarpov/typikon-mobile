# Уставные чтения — иконка

Общий стиль с «ЦС Словарём»: фон #850014, круг #faf5de с обводкой #060606,
буква «Т» из встроенного Monomakh Unicode. Внешний фон занимает весь квадрат;
светлый круг имеет радиус 448 при размере 1024. Буква вписана в область 610×610.

Исходник — app-icon.svg, буква переведена в кривые и не требует шрифта при
отображении. app-icon.png и assets/logo.png — непрозрачные растровые варианты.

Пересоздать ресурсы: `python scripts/generate_icon.py` из корня проекта.
Нужны только инструментальные Python-пакеты Pillow и fonttools.
Генератор обновляет PNG для Android/iOS и векторные adaptive-ресурсы Android.

В Android 8+ фон и передний план разделены. Передний план масштабирован на
72/108, чтобы светлый круг и цветной ободок оставались видны при круглой маске.
adaptive-foreground.png и параметры flutter_icons в pubspec.yaml сохраняют
те же пропорции при использовании flutter_launcher_icons.
