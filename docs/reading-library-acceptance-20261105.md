Выпуск включает оба сценария: читать книгу подряд и собирать тему по нескольким источникам.

- Веб: https://www.typikon.info/study — вход также из прежней библиотеки и читателя.
- APK: [Typikon 2.3.7+18](/Users/georgecarpow/StudioProjects/Typikon/build/acceptance/typikon-2.3.7-reading-library-20261105.apk).
- Код веба: ветка `codex/reading-library`, итоговая ревизия `d2354b86f0929a2b72f1e3270268f58e851734dd`.
- Публичный Android остаётся 2.3.4. APK не размещён в публичном каталоге обновлений.

## Редакционное покрытие

Три маршрута: «О молитве» — 7 отрывков; «Покаяние и возвращение» — 6; «Пасха в Писании и богослужении» — 8. Вместе 21 отрывок из 18 уникальных источников чтения. У каждого есть вводка, основания переходов и точные адреса.

Подготовлены 22 связи: 3 толкования, 1 цитирование и 18 тематических переходов. Толкования привязаны к Ин 1:1, Мф 4:1 и Деян 1:2–3. Цитата Рим 2:13 во вводной беседе на Бытие обозначена как цитата. Единственная наполненная вводная беседа не выдаётся за покрытие всех глав Бытия.

Проверка означает сверку с опубликованными текстами действующего корпуса; внешняя научная или церковная экспертиза не заявляется. Остальная библиотека может не иметь подготовленных связей. Подтверждённых соответствий фрагментов разных редакций в начальном наборе нет: они открываются независимо; сравнение предлагается только при наличии проверенного соответствия.

## Результаты проверок

- Полный мобильный набор на окончательном коде: **1007 тестов прошли**.
- Итоговые целевые проверки веба, схем, старых сериализаторов и плана чтения: **62 теста прошли**. Проверка TypeScript прошла.
- Развёртывание, переключение, проверка готовности и откат: **18 тестов прошли**.
- Общий веб-прогон: 1448 тестов, 1443 прошли, 2 пропущены, 3 первоначальных сбоя. Несоответствие схемы TextDetail исправлено и перепроверено; два сценария отката превысили 20-секундный лимит под общей нагрузкой и затем прошли отдельным прогоном всех 18 сценариев.
- На изолированной MongoDB с искусственными пользователями проверены старые ID, повтор операций, конфликт версий, изоляция владельцев, запрет ложной привязки цитаты, безопасная публикация, скрытие отозванного источника и повтор создания плана без сброса указателя. Дополнительно проверены удаление отклонённой записи, ручная коррекция её адреса и сохранение первоначальной выписки.
- На проде для всех 21 контекстов отдельно проверено, что связь относится именно к нужному источнику и ведёт к противоположному фрагменту. Используется настоящий ключ, извлечённый в памяти из окончательного APK: проверяются все 21 отрывок, связанный API Библии, толкования, полный пакет, прежние «Спутник» и «Личный круг». Личный API без сессии должен отвечать `401 session_required`; это не отказ ключу. Реальные личные записи пользователя на проде для тестов не изменялись.
- В браузере проверены запись вопроса, поиск, фильтр открытых вопросов, копия маршрута, переход к толкованию и возврат. Проверены последовательные главы книги и сохранение явного статуса.
- Холодная проверка веба: скачана вся «Лествица» (55 текстов, около 1,02 МБ), источник HTTP полностью отключён, исходная вкладка закрыта. Новая вкладка открыла сохранённую оболочку, вопрос, вторую главу со статусом «Отложено» и следующую главу без сервера. Проверка выполнялась через ограниченный публичный ретранслятор без ключей и сессий, а не через доступ к production MongoDB.
- Подпись APK совпадает с предыдущими приёмочными сборками. Установка на физический Android остаётся частью приёмки владельцем.
